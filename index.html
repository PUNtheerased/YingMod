HOW TO PLAY

นั่งห่างกล้อง 50–80 ซม. ในที่มีแสงพอ ยกมือ 1 ข้างหันฝ่ามือเข้ากล้อง แล้วใช้ท่ามือเหล่านี้

FINGER GUN

ชูนิ้วชี้ ตั้งนิ้วโป้งขึ้น นิ้วอื่นกำไว้ = ท่าพร้อมยิง

FIRE

กดนิ้วโป้งลงแตะนิ้วชี้ = ยิง กดค้าง = ยิงต่อเนื่อง ยกขึ้น = หยุด

MOVE

เลื่อนมือซ้าย–ขวา ยานเคลื่อนตาม (ใช้ตำแหน่งกลางฝ่ามือ)

FIST = SHIELD

กำมือทุกนิ้ว เปิดโล่ 3 วินาที แล้วต้องรอชาร์จ

V SIGN = WEAPON

ชูนิ้วชี้กับนิ้วกลาง สลับอาวุธ NORMAL / LASER / MULTI (ไม่ยิง)

OK = BOMB

ปลายนิ้วโป้งแตะปลายนิ้วชี้ นิ้วอื่นเหยียด ทิ้งระเบิดเคลียร์จอ (มีจำนวนจำกัด)

OPEN PALM = PAUSE

แบมือค้าง 0.8 วินาที = หยุดเกม · ทำท่าปืนค้าง 1 วินาที = เล่นต่อ

KEYBOARD / MOUSE

A/D หรือ ← → ขยับ · Space ยิง · Q อาวุธ · C โล่ · B ระเบิด · P หยุด · เมาส์ลากและคลิกยิง
